## Fișa de investigație (feedback între colegi)

La curs, profesorii își schimbă fișele și le verifică după patru criterii, apoi dau feedback prin „două stele și o dorință”: două lucruri reușite și unul de îmbunătățit.

| Criteriul | Da | Încă nu |
|---|---|---|
| Întrebarea se poate testa cu Labdisc. | | |
| Variabilele sunt clare: ce schimbăm, ce măsurăm, ce păstrăm la fel. | | |
| Timpul e realist pentru o lecție. | | |
| Elevului i se cere să interpreteze datele, nu doar să le colecteze. | | |

Întrebare în plus: ce face un elev care termină primul?

## Raportul de investigație al elevilor

| Criteriul | Ce arată un raport bun |
|---|---|
| Întrebarea | Se poate răspunde la ea prin măsurare. |
| Ipoteza | Spune ce se schimbă, ce măsurăm și ce păstrăm la fel, și de ce. |
| Datele | Măsurarea e repetată; condițiile sunt notate. |
| Graficul | Are adnotări în momentele importante. |
| Concluzia | Răspunde la întrebare și se poate citi direct de pe grafic. |
| Erorile | Numește cel puțin două surse de eroare și cum le-ar reduce. |

> [!info] În lucru
> Nivelurile de performanță pentru fiecare criteriu se adaugă după prima aplicare la clasă.
