**Experiență de laborator**

**Investigarea mediului acido-bazic al substanțelor utilizate în activitatea cotidiană.**

**Ustensile și reactivi:** Dispozitivul Labdisc, electrod de pH, pahare Berzelius (100 ml), hârtie de indicator universal, apă distilată pentru spălarea electrodului, apă plată (de la robinet), soluție de săpun lichid, oțet alimentar diluat, suc de lămâie, apă minerală carbogazoasă, cafea, ceai negru, ceai verde, soluție de glicerină, ser fiziologic.

**Mod de lucru:**

1.  Așezați paharele Berzelius pe masa de lucru și etichetați-le corespunzător fiecărei soluții de analizat. Turnați aproximativ 20 ml din fiecare soluție în paharul corespunzător.
2.  Introduceți câte o bucățică de hârtie indicator universal în fiecare pahar, folosind o baghetă de sticlă curată pentru fiecare soluție.
3.  Comparați culoarea obținută cu scala de culori de pe cutia indicatorului.
4.  Notați valoarea aproximativă a pH-ului în tabelul de observații.
5.  Conectați senzorul de pH la dispozitivul Labdisc.
6.  Introduceți electrodul în prima soluție. Așteptați 10-15 secunde până când valoarea se stabilizează pe ecran.
7.  Notați valoarea exactă a pH-ului cu o zecimală.

**Atenție!** Spălați electrodul cu apă distilată din pisetă și uscați-l ușor cu un șervețel înainte de a-l introduce în următoarea soluție, pentru a evita erorile de măsurare.

8.  Repetați procedura pentru toate celelalte probe.
9.  În baza experimentelor realizate completați tabelul conform cerințelor:

| Nr. probei | Soluția cercetată         | pH determinat cu ajutorul indicatorului universal | pH determinat cu Labdisc |
|------------|---------------------------|---------------------------------------------------|--------------------------|
| 1          | apă plată                 |                                                   |                          |
| 2          | soluție de săpun lichid   |                                                   |                          |
| 3          | oțet alimentar diluat     |                                                   |                          |
| 4          | suc de lămâie             |                                                   |                          |
| 5          | apă minerală carbogazoasă |                                                   |                          |
| 6          | cafea                     |                                                   |                          |
| 7          | ceai negru                |                                                   |                          |
| 8          | ceai verde                |                                                   |                          |
| 9          | ser fiziologic            |                                                   |                          |
| 10         | soluție de glicerină      |                                                   |                          |

10. Comparați precizia datelor obținute cu hârtia indicator față de senzorul pH și laboratorul digital Labdisc. În ce situații din viața reală sau din industrie o diferență de 0,5 unități de pH poate fi critică?
